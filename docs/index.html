Before you arrive

Bring

  • A Windows laptop with administrator rights — Git for Windows needs them to install.
  • VS Code, with the Python and Jupyter extensions.
  • A GitHub account with two-factor authentication already working on your phone.
  • No Python install needed — uv downloads the interpreter the project pins.

Want a head start? Install both tools the evening before — uv with the command below, Git for Windows from git-scm.com — then run the setup block on the right so the libraries are already downloaded.

PowerShell · install uv
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Get the files and set up Section 2

Clone this repository — or download it as a ZIP — then create the project you will use from Section 2 onwards.

PowerShell
git clone https://github.com/wooihaw/workshop-python-ml-2026.git

uv init ai-workshop
cd ai-workshop
uv python pin 3.14
uv add numpy pandas matplotlib scikit-learn
uv add joblib jupyterlab
uv run python -c "import numpy, pandas, sklearn"

Then copy the repository's data folder into ai-workshop, so the exercises find data/sensors.csv and data/readings.csv.
